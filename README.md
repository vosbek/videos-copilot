## Demo Repo

Base: Fork of [github-samples/agents-in-sdlc](https://github.com/github-samples/agents-in-sdlc) (Tailspin Toys - Flask + Astro/Svelte + SQLite)

Each video has two branches:
- `video/[ID]-[slug]` - Starting state for following along
- `video/[ID]-complete` - Finished state after the video

The demo repo is also the **resource kit** handed to viewers: all agents, skills, hooks, MCP configs, and evals in one place.

---

## How to Use This Repo

1. **Review scripts** in order by phase
2. **Set up demo repo branches** per the branch spec in each script
3. **Follow the Camtasia Guide** for recording setup
4. **Record by phase** using the phase checklists
5. **Check off** each video as you go
6. **Use templates** for any new videos added later
